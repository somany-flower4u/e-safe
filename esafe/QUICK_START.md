**좌측 사이드바 (컨트롤):**
- 📹 **비디오 소스 선택**
  - 웹캠 사용 (실시간)

  - 데모 모드 (샘플 영상)

- ⚙️ **감지기 설정**
  - 에스컬레이터 방향 선택
  - 각 감지기 임계값 조정
  - 혼잡도 임계값 설정

- ▶️ **시작 버튼**
  - 클릭하여 실시간 감지 시작

**중앙 (비디오 표시):**
- 실시간 영상 피드
- 감지된 객체 표시
- 위험 알림 배너

**우측 패널 (상태):**
- 현재 인원 수
- 각 위험 상태 표시
- 혼잡도 게이지

## 🎮 사용 방법

### 웹캠 사용하기
1. 사이드바에서 "웹캠"을 선택
2. 방향(↑/↓) 선택
3. "시작" 버튼 클릭
4. 실시간 감지 시작

### 비디오 파일 사용하기
1. 사이드바에서 "비디오 파일 업로드" 선택
2. MP4/AVI 파일 업로드
3. "시작" 버튼 클릭
4. 비디오 처리 시작

## 🔧 앱이 응답하지 않으면

### 1. Streamlit 재시작
터미널에서:
```bash
cd esafe
streamlit run app.py
```

### 2. 포트 확인
```bash
netstat -ano | findstr :8501  # Windows
lsof -i :8501                 # Mac/Linux
```

### 3. 브라우저 캐시 정리
- Ctrl+Shift+Delete (캐시 삭제)
- 또는 시크릿 모드로 접속

## 📊 감지기 설명

### 🏠 캐리어 감지
- **방치**: 3초 이상 움직이지 않는 수하물
- **낙하**: 빠르게 떨어지는 수하물
- **결과**: 🔴 긴급 알림

### 👤 낙상 감지  
- **쓰러짐**: 어깨/엉덩이가 무릎보다 아래
- **의식불명**: 2초 이상 쓰러진 상태
- **결과**: 🔴 긴급 알림

### ↔️ 방향 감지
- **역방향**: 에스컬레이터 반대 방향 이동
- **감지 시간**: 1.5초 이상
- **결과**: 🟠 경고 알림

### 👶 영유아 감지
- **단독 탑승**: 보호자 없는 어린이
- **캐리어 탑승**: 수하물 위에 있는 어린이
- **결과**: 🟠 경고 알림

### 👥 혼잡도 감지
- **기본값**: 5명 초과시 주의
- **조정 범위**: 2~10명
- **결과**: 🟡 주의 알림

## 🆘 문제 해결

**Q: "웹캠을 찾을 수 없습니다" 오류**
- A: 웹캠이 연결되어 있는지 확인
- 다른 앱에서 웹캠을 사용 중인지 확인
- 브라우저에 웹캠 권한 부여

**Q: 비디오가 느리게 처리됨**
- A: 비디오 해상도 감소
- CPU 사용 프로세스 종료
- 감지 감도 조정

**Q: "감지된 객체 없음" 표시**
- A: 카메라 초점 확인
- 조명 상태 개선
- 사람이 ROI(녹색 영역) 내에 있는지 확인
